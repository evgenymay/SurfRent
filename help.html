SurfRent

Бесплатное приложение для учёта проката оборудования, снаряжения, инвентаря и устройств. С почасовой и подневной тарификацией.

Вы сможете контролировать:

  • выдачу и приём инвентаря, устройств и оборудования;
  • наличие свободных слотов времени для каждого оборудования с учётом уже оформленной на него брони;
  • всё выданное на текущий момент снаряжение;
  • расчёты с клиентами и оплату заказов;
  • демо-база для лёгкого старта.

Экраны приложения

Настройки

  • можно загрузить демо-базу для лёгкого старта;
    • при очистке демо-базы данные, которые вы уже ввели сами, сохранятся;
  • изменить размер всех шрифтов под ваш экран для удобства чтения.

Клиенты

  • список клиентов с идентификацией по номеру телефона;
  • поиск по номеру телефона, имени или заметкам;
  • денежные расчёты по заказам;
  • количество активных заказов по каждому клиенту.

Оборудование

  • списки инвентаря/услуг с ценами по часам, дням, неделям или месяцам;
  • количество каждой позиции на складе;
    • если количество = 0, это — неограниченные Бронирования (например — спасательные жилеты, страховки, хранение клиентского инвентаря);
  • карточка Оборудования имеет два состояния: Выбор / Редактирование;
    • Редактирование — добавлять/удалять/редактировать цены текущей позиции;
    • Выбор — переход по клику на экран Бронирования.

Бронирование

  • Бронирование = Бронирование + количество + интервал бронирования;
  • под каждой позицией показывается, сколько единиц свободно в каждый момент времени. Интервал бронирования задаётся одним нажатием по свободному слоту или вводится вручную. Это страхует от нехватки инвентаря при пиковой загруженности.

Заказы

  • после выбора интервала бронирования создаётся Заказ;
  • Правило: 1 предмет проката = 1 Заказ. Клиент хочет 3 SUP на 2 часа — создаётся 3 отдельных заказа. Это страхует от ситуаций, когда часть инвентаря хотят продлить или отменить. Даёт контроль над всеми выданными предметами поштучно (часть досок вернули, часть ещё нет);
  • почасовая аренда учитывается по фактическому времени, подневные заказы — по датам;
  • внутри заказа можно вести журнал приёма/выдачи оборудования, если он допускает несколько сеансов (например — взяли сёрф на несколько дней и катаются по несколько раз в день).

Выдано

  • список всех комплектов, которые пока не вернули (находятся на руках у клиента);
  • кликом по позиции вы можете посмотреть, в каких заказах она задействована.
